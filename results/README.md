# Results index

All files here are generated by the scripts in `../scripts/` from the raw outputs in `../runs/`.
`python scripts/verify_results.py` re-scores every run and checks these tables against them.
"dev" = 30 development documents, "test" = 120 evaluation documents (see the main README).

Run directory names in `../runs/` encode the configuration:
`staged` / `allinone` (task decomposition), `G` / `noG` (guidelines), `retrieval3` / `random3` / `none`
(demonstrations and k), `V` / `noV` (verification), `goldtrig` (gold triggers given),
`unseen-...` (held-out types), then model and split; `_rep1`, `_rep2` are the repeated runs.
The final configuration is `staged_G_retrieval3_V`.
